## 🧾 Descrição Geral

Este repositório reúne um conjunto de aplicativos Android desenvolvidos como parte da disciplina de Programação Mobile, com foco na prática de componentes como CheckBox, RadioButton, TextInputLayout, ImageView, navegação entre múltiplas Activities e passagem de dados com Intents e Bundles.

Ao longo do projeto, foram criadas quatro aplicações distintas:

Simulador de Compras: marcação de produtos com cálculo automático do valor total.

Reajuste Salarial: cálculo de novo salário com base em percentuais pré-definidos.

Cadastro de Clientes (Loja Tem de Tudo): fluxo completo de registro com personalização da mensagem final.

Registro de Pedidos (Lanchonete Lanche Fácil): escolha de lanche e nome do cliente com resumo final.

Todas as aplicações seguem uma arquitetura limpa, com separação de responsabilidades, uso adequado de layouts XML e atenção à experiência do usuário. Os desafios enfrentados, como navegação entre telas e tratamento de dados dinâmicos, foram superados com foco em boas práticas e reutilização de código.
